# efficiovirtual website

The website for **efficiovirtual**, a digital marketing studio. It's a story-led site with a 3D scene that moves as you scroll.

Built with [Next.js](https://nextjs.org) (a popular React framework), [Tailwind CSS](https://tailwindcss.com) for styling and [three.js](https://threejs.org) for the 3D. You don't need to know these to edit text or colours — see "Common edits" below.

---

## Preview the site on your computer

You only need to do steps 1–2 once.

1. **Install Node.js** (version 18 or newer) from https://nodejs.org — choose the "LTS" download and install it like any other app.
2. **Open a terminal in this folder and install the project's packages:**

   ```bash
   npm install
   ```

3. **Start the preview:**

   ```bash
   npm run dev
   ```

4. Open **http://localhost:3000** in your browser. The page updates automatically when you save a file.
5. To stop the preview, go back to the terminal and press `Ctrl + C`.

### Check it before publishing (optional)

```bash
npm run build
```

If this finishes without errors, the site is ready to deploy. To see that production version locally, run `npm start` afterwards.

### Publish it

The easiest way is [Vercel](https://vercel.com) (free for personal use): sign in with GitHub, click **Add New → Project**, choose this repository and click **Deploy**. No settings are needed.

## Adding your own logo and images

- **Logo:** the site already uses a vector version of the logo you supplied (in `lib/logo.ts`). To use your own file instead, put it in `public/brand/` (for example `public/brand/logo.svg`) and set `logoFile: "/brand/logo.svg"` in `lib/site.ts`. Its proportions are kept automatically.
- **Browser tab icon:** replace `app/icon.svg` (and `app/apple-icon.png`, 180×180 px, for iPhone home screens).
- **Social sharing image:** generated by `app/opengraph-image.tsx`. To use a photo instead, delete that file and add `app/opengraph-image.png` (1200×630 px).
- More details are in `public/brand/README.md`.

No client logos, testimonials or statistics are included — add real ones only.

## Case studies

The Case Studies page (`/case-studies`) shows eight placeholder cards until you add real projects. Edit `lib/caseStudies.ts`:

1. Replace a placeholder with your project details: client, title, industry, country, services, summary, challenge, what you did and results. Only use real, approved information.
2. Optional: put an image in `public/case-studies/` (about 1600×1000 px) and set `image: "/case-studies/your-image.jpg"`.
3. Set `published: true`.

Each published case study gets its own page at `/case-studies/<slug>` and is added to the sitemap. While all eight are placeholders, the Case Studies page is hidden from Google so unfinished content doesn't affect your SEO.

## SEO

What's already set up:

- Every page has its own title, meta description, canonical URL, link-preview image (Open Graph / Twitter) and exactly one H1. Use the `pageMeta()` helper in `lib/seo.ts` for any new page.
- Structured data (JSON-LD): business details on the homepage, Service and Breadcrumb data on service and country pages, FAQ data where there are FAQs. Only verified details are included — no address, phone number, reviews or ratings.
- `sitemap.xml` and `robots.txt` are generated automatically (`app/sitemap.ts`, `app/robots.ts`).
- Temporary `*.vercel.app` addresses send a "noindex" header (`middleware.ts`), so only your real domain appears in Google.
- The 3D scene only loads on devices with graphics acceleration and after the page has loaded, so text appears quickly.

Before Google can index the site:

1. Connect **efficiovirtual.com** in Vercel → Project → Settings → Domains. Until then, all canonical URLs and the sitemap already point to efficiovirtual.com.
2. Add the site to **Google Search Console** (search.google.com/search-console) as a URL-prefix property for `https://efficiovirtual.com`. Choose the **HTML tag** method, copy only the code inside `content="…"`, and set it as `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` in Vercel → Settings → Environment Variables (or paste it into `lib/site.ts`). Redeploy, then click **Verify**.
3. In Search Console, open **Sitemaps** and submit `sitemap.xml`.
4. Optional: do the same in **Bing Webmaster Tools** using `NEXT_PUBLIC_BING_SITE_VERIFICATION`.
5. Once your Google Business Profile is live, add its link and any confirmed business details (address, phone) to the structured data in `app/page.tsx`.

## How the 3D and motion work (for the curious)

- `components/Scene.tsx` draws one 3D world behind the pages: glass panels, a glowing thread, the ev logo as a 3D emblem, five service objects and soft particles, lit with plum, pink and terracotta.
- Each homepage chapter is a `<section data-chapter …>`. As you scroll, the scene moves smoothly from one chapter's layout to the next and pauses while a chapter is on screen.
- Mouse: gentle parallax on the 3D objects and a slight tilt on cards. Touch screens: no cursor effects; scrolling adds a gentle sway and the card in the middle of the screen lights up its 3D object.
- Motion effects stay on for everyone. If a device asks for **reduced motion**, only the constant background drifting pauses.
- Devices without a graphics card get a lighter version of the 3D. Only if WebGL isn't available at all (and for search bots and speed-test tools) does the site show a static logo and gradient instead.

## Contact form

The form opens the visitor's email app with their message filled in, addressed to `admin@efficiovirtual.com`. Nothing is stored on a server. To receive messages without the visitor's email app, you'd add a form service (such as Formspree) later.
